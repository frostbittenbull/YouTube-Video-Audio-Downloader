# ⬇️ YouTube — Video & Audio Downloader

[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-Ready-success.svg)](#установка)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Пользовательский скрипт (Userscript) для браузера, который добавляет полноценное скачивание видео и аудио прямо со страницы YouTube — как на обычных видео, так и в Shorts. Скрипт умеет доставать прямые ссылки на медиапоток напрямую с серверов Google, а если это не удаётся — честно помечает такие дорожки недоступными, вместо того чтобы зависать в ненадёжном фолбэке.

Особенность данного скрипта — **нативная интеграция** в интерфейс сайта и **ремукс видео и аудио прямо в браузере** через Mediabunny/WebCodecs, без ffmpeg и без стороннего бэкенда!

## 🌟 Основные возможности

- **Прямые ссылки без SABR:** Скрипт обращается к внутреннему API YouTube от имени нескольких клиентов по очереди (`ANDROID_VR`, `WEB_EMBEDDED_PLAYER`, `IOS`, `TVHTML5`, `ANDROID`, `MWEB`, `WEB` и др.), прикладывая анонимный `visitorData` — там, где это срабатывает, видео и аудио скачиваются напрямую с серверов Google на полной скорости, без ограничений SABR.
- **Честная маркировка недоступных дорожек:** Если для какого-то качества прямую ссылку получить не удалось, пункт в меню становится серым и подписывается «(недоступно)» — вместо того чтобы проваливаться в SABR-стриминг, который без настоящей аттестации устройства надёжно зависает.
- **Расшифровка подписи на лету:** Если формат приходит с `signatureCipher`, скрипт сам находит и выполняет функцию расшифровки прямо из `base.js` плеера — без необходимости вручную поддерживать актуальность алгоритма.
- **Обход возрастных ограничений (18+):** Часть запросов идёт через контекст «встраивания» (`WEB_EMBEDDED_PLAYER` + `embedUrl`) вместе с явным подтверждением `contentCheckOk`/`racyCheckOk` — это снимает возрастную проверку без авторизации, если автор видео разрешил встраивание на сторонних сайтах.
- **Ремукс без ffmpeg:** Скачанные видео- и аудиопотоки собираются в готовый файл прямо в браузере через Mediabunny (WebCodecs) — сервер и сторонние программы не нужны.
- **Гибкий выбор дорожек:** Отдельное меню для скачивания «видео + аудио» и отдельно только аудио, с сортировкой по качеству/битрейту и кодеку — вплоть до **2K (1440p)**, **4K (2160p)** и **8K (4320p)**, если видео выложено в таком качестве. Для каждого разрешения видео скрипт сам выбирает лучший доступный кодек по приоритету **AV1 → VP9 → AVC1 (H.264)**; для аудио — **Opus → AAC (mp4a)**.
- **Корректные расширения файлов:** Готовый файл сохраняется через нативный `<a download>` — с точным указанным расширением (`.mp4`, `.m4a`, `.webm`), без «сюрпризов» с переименованием.
- **Нативный интерфейс:**
  - На обычных видео скрипт использует и оживляет родную кнопку «Скачать» (в том числе снимая с неё скрытие или убирая мешающую кнопку «Спасибо», если из-за неё «Скачать» утекает в выпадающее меню «…»), либо добавляет свою кнопку в том же стиле, если родной нет вовсе.
  - На Shorts добавляется отдельная круглая кнопка прямо в панель действий — над кнопкой «Нравится», в том же визуальном стиле, что и остальные.
  - Во время загрузки доступны кнопки ⏸ Пауза/▶ Продолжить и ❌ Отмена, чтобы остановить или прервать процесс в любой момент — крестик в углу окна лишь прячет его (загрузка продолжается в фоне), по-настоящему останавливает только «Отмена».
  - Окно загрузки можно свернуть в маленький плавающий виджет (только полосы прогресса, без текста) — перетаскивается мышью и сам прилипает к ближайшему углу страницы, запоминая его для следующего сворачивания; сворачивание/разворачивание анимировано.
- **Прогресс-бары по каждому потоку:** Во время скачивания отдельно видно прогресс видео и аудио — в мегабайтах, процентах, а также в реальной скорости (кбит/Мбит/Гбит в секунду) и оставшемся времени.

## 🎨 Бесшовный дизайн (Стиль)
Интерфейс загрузчика разработан с полным уважением к оригинальному дизайну YouTube. Все элементы управления продуманы до мелочей:
- Собственная кнопка «Скачать» использует те же CSS-классы, что и родные кнопки интерфейса («Нравится», «Поделиться», «Сохранить») — то же скругление, тот же шрифт, тот же ховер.
- Кнопка в Shorts визуально неотличима от соседних круглых кнопок (лайк, комментарии, поделиться, ремикс).
- Скрипт выглядит и ощущается не как стороннее дополнение, а как родная, встроенная функция сервиса.

## 🎧 Как использовать

1. Откройте любое видео на [youtube.com](https://www.youtube.com) — обычное или Shorts.
2. Рядом с «Нравится»/«Поделиться» (на Shorts — над «Нравится») появится кнопка **«Скачать»**.
3. Нажмите на неё — откроется меню с доступными качествами видео и аудио. Серые пункты с пометкой «(недоступно)» — те, для которых прямую ссылку получить не удалось; кликать по ним нет смысла.
4. Выберите нужное качество — начнётся скачивание с прогресс-баром по каждому потоку, а по завершении браузер сам предложит сохранить готовый файл.

## ⚙️ Технические детали (для тех, кому интересно)

- Формат запрашивается у внутреннего API YouTube (`/youtubei/v1/player`) от имени нескольких клиентов по очереди (`ANDROID_VR`, `WEB_EMBEDDED_PLAYER`, `IOS`, `TVHTML5`, `ANDROID`, `MWEB`, `WEB` и др.) — у каждого свои условия и ограничения, и какой-то из них с большей вероятностью отдаст прогрессивную ссылку без принудительного SABR.
- К запросу прикладывается только `VISITOR_DATA` из `ytcfg` — анонимный ID сессии, который есть даже в приватном окне без единой куки. Сигналы именно залогиненного профиля (`identity-token`, `SAPISIDHASH`) намеренно не отправляются: на практике их присутствие иногда только повышает подозрительность запроса, а не снижает её.
- Если сервер всё равно требует подтверждения (`LOGIN_REQUIRED`) или отдаёт только SABR-метаданные без прямой ссылки — это решение принимает антибот-система YouTube в моменте, и обойти его без полноценной эмуляции BotGuard (аттестации устройства) невозможно. Именно поэтому часть дорожек может быть недоступна, и это не баг.
